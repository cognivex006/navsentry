What this recorder never does
  • Never stores what you type: a step says only which field you used. There is no screenshot right after typing or on a password field. A later screenshot can still show text that stays on the page, so record with test data.
  • Never sends anything: it has no network access. The file is saved only where you choose.
  • Records only the tab you started, on origins in your imported scope. Leaving the scope pauses recording, and other tabs are never photographed.

Next: import it with NavSentry
  1. Open a page of the site in your scope.
  2. Press Record, then use the site as a user would.
  3. Press Stop, review the steps, and press Save file.
